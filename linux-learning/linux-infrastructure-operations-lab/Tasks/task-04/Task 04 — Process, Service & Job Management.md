

## Scenario

```
As a Junior Linux System Administrator, I was responsible for
monitoring system processes, managing services, controlling
process execution, and configuring scheduled maintenance jobs
on a Debian Linux server.
```

## Objectives

```
Inspect running processes
Understand PID and PPID
Monitor CPU and memory usage
Search for processes
Send signals to processes
Stop and resume processes
Manage process priority
Manage systemd services
Create a custom systemd service
Configure a scheduled maintenance job
Verify scheduled task execution
Perform basic service/job troubleshooting

```
