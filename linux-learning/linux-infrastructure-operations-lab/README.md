## Overview

This project is a hands-on Linux infrastructure laboratory
designed to simulate the day-to-day responsibilities of a
Junior Linux System Administrator.

The environment is built using Debian 13 running inside
VirtualBox.

Rather than documenting isolated Linux commands, the project
evolves through a series of realistic infrastructure,
administration, troubleshooting, automation, and security
scenarios.

---

## Project Scenario

Nexa Engineering is a small engineering company that relies
on Linux infrastructure for internal applications,
engineering data, user accounts, and operational services.

The goal of this project is to design, configure, maintain,
troubleshoot, automate, and secure a Linux-based environment
for the company.

## Project Objectives

The project focuses on practical Linux system administration
skills including:

- Linux system installation and configuration
- Hardware and system inspection
- Boot process and system targets
- Package management
- Command-line administration
- File and filesystem management
- Partitioning and storage
- LVM
- Mount management
- Users and groups
- Linux permissions
- Process management
- Service management
- Networking
- Network troubleshooting
- System logs
- Bash scripting
- Task scheduling
- Backup automation
- System monitoring
- Basic Linux security

## Phase 1 — Server Foundation

### Task 01 — Server Discovery & Initial Inventory

The initial task focused on discovering and documenting
the baseline configuration of a newly provisioned Debian
Linux server.

The following areas were inspected:

- Operating system
- Kernel
- CPU
- Memory
- Storage
- Filesystems
- Network configuration
- Routing
- DNS
- System uptime
- Logged-in users
- System state
