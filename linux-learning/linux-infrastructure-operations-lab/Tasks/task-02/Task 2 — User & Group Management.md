
## Scenario

```
A new development team has been assigned access to a Debian Linux server.

The objective was to create user accounts, organize users into groups,
and configure a shared project directory with appropriate permissions.

```
## Objectives
```

Create Linux users
Create and manage groups
Configure user membership
Verify UID and GID information
Create a shared project directory
Configure ownership and permissions
Apply SGID to the shared directory
Verify the final configuration

```
